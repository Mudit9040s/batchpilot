2024 · Where it started

ColPal — our first API-first client

Colgate-Palmolive was the first deployment where APIs weren't a side-channel — they were the only channel. Orders, products, images, outlets: everything moved through bulk endpoints. Automation wasn't nice-to-have. It was the key to going live.

2024
ColPal onboarding begins. Massive data volumes, hard deadlines, APIs everywhere.
The gap
No internal tool existed for bulk API operations — Postman, one request at a time, was the default.
The bet
Write Python in Google Colab and automate everything we possibly could.
2024–2026 · The Colab era

One notebook at a time

Every repetitive task became a script. A private arsenal of automations grew:

🛒
Order processor

End-to-end order ingestion for ColPal — JSON built and pushed automatically.

🖼️
Image compressor

Every product image squeezed to ≤20 KB — thousands processed in one run.

📦
Batch JSON engine

Requests fired in batches of 100 with retries — the script that became BatchPilot's heart.

🔑
Token reader + retry loop

Read the web session token, replayed requests as the client, saved every failure to Excel, and re-hit just the failures.

But there was a catch

The scripts worked. The system didn't.

😰 The hidden costs

  • Credentials hardcoded in notebooks — a security incident waiting to happen
  • Only one person could run them — single point of failure
  • No validation — bad rows discovered after hitting production
  • No audit trail, no reports, no visibility for the team

💡 The realization

  • Every ops teammate has this exact spreadsheet→API problem
  • The script logic was proven over 2 years of production use
  • AI could add the judgment layer scripts never had
  • What if this became a product anyone could use?

Built for non-coders

Five fields. That's the whole job.

API URL · username · password · batch size · file. The tool does the rest — including holding back bad rows and explaining every rejection.

🧪
Playground mode

A built-in fake API with partial acceptance — anyone can learn the tool in 60 seconds with zero risk.

📁
Saved profiles

FieldAssist outlet create/update, price update, DMS invoices — pre-configured with real validation rules from the API docs.

🗺️
Column mapping

Headers pre-read from the file; rename to API field names or drop columns — right in the browser.

Under the hood · QA'd hard

Small tool. Serious engineering.

🔐
Security first

Login-gated portal, credentials only in env vars, SSRF guard on user-entered URLs, confirm-before-send.

👥
Multi-user safe

WAL-mode SQLite, atomic send-claims (no double sends), threadpool uploads — verified with 50 concurrent users.

🧪
Tested everything

Unit suite + CI on every push + edge-case battery: Hindi text, ₹1,000-style numbers, +91 phones, broken JSON, partial acceptance.

🆓
₹0 infrastructure

Open source (MIT), deployed on a free tier, in-app user guide. Anyone can audit, extend, self-host.
